# 來源與測試邊界

- 本版基於 [claude-video-specs-lite](https://github.com/mathruffian-dot/claude-video-specs-lite)，原版完整參考檔可至上游查閱，本版保留 MIT 授權與三類影片的簡化規範。
- 改編重點：明確區分自製簡化圖卡和原版動畫流程；支援不需獨顯的 CPU FFmpeg 路線；字幕保留 SRT 初稿與人工聽審界線；不預設安裝、上傳影片、使用付費金鑰或 MCP 已連線。
- 官方 Antigravity 工作區規則與 MCP 設定來源：[Rules](https://antigravity.google/docs/rules-workflows?tab=ide)、[MCP](https://antigravity.google/docs/mcp)。本次沒有在其他教師帳號或其他版本 IDE 測試本專案的自動讀取／操作。
- 本機 Windows PowerShell 5.1 用工作區隔離環境中的 Python 3.12、Pillow、imageio-ffmpeg 與線上 edge-tts 成功輸出五場有聲版，H.264、1280×720、24 fps、AAC，約 31.71 秒；FFmpeg 全檔解碼成功，已抽看各場畫面。測試機原本已有 Python 與 FFmpeg，但此流程使用工作區內版本。**未逐字人耳聽審或以真實低規電腦測速**。
- `字幕初稿.srt` 用場景長度估計，不是經逐詞對齊之轉錄字幕；有旁白版本需要聽審，靜音版的旁白稿只可當待配音腳本。範例 MP4 未燒錄字幕。
- 上游 HTML/Playwright 流程及其技能包裝、Antigravity 版本 IDE 全流程、學校網路和無獨顯電腦的效能，都沒有因本版腳本成功就獲驗證。
- 本機另以 Antigravity `agy` CLI 指定在本工作區讀取 `README.md` 和 `AGENTS.md`，並執行只讀設備檢查成功；首次無頭執行因無法互動授權命令而被拒，第二次使用本次生效的限權設定成功。這不等於 IDE 已驗證自動載入；CLI 與 AI 模型服務仍可能需要網路和帳號。
