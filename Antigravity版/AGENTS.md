# Antigravity 研習影片：工作區指引

使用繁體中文與使用者溝通。先讀根目錄 `README.md`，依使用者授權和已知條件執行；不重複要求已提供的資料。不要把這份指引當成代表任何服務已連線。

## 預設目標

- 一般國中小教師使用 Windows、可能沒有獨立 GPU；以可在研習中完成一支短影片為優先。課前設備與操作測試不等於測驗學員知識。
- 依任務選 `規範/01-活動紀錄.md`、`規範/02-教學影片.md` 或 `規範/03-社群科普.md`；使用者的時間、內容和工具需求優先於預設長度。
- 本資料夾是工作區版本。Google 文件描述根目錄 `AGENTS.md` 規則可被載入；是否在特定 IDE／CLI 生效仍需在該環境驗證。使用者可要求你明確讀取本檔。

## 先確認路線

1. **從零製作動畫／解說影片**：依 3–5 格分鏡草擬教學內容與旁白；可在本機執行 `工具/製作示範.py` 作設備煙霧測試。原始參考含 HTML 範例與完整三類製作規範，但它們有不同依賴，不能把示範當原流程端到端驗證。
2. **剪輯既有影片**：先保留原片，再使用 Concat 手動或已連接的 Concat MCP，另以本機 VAD、faster-whisper 或人工操作處理停頓與字幕。MCP 並非預設已連線；依 `選配/Concat-MCP.md` 核實。若不可用，明確告知並採用手動備援。
3. **從文字製作 SRT**：先確定實際剪接版本；有旁白時檢查文字和聲音同步。若只有場景估算時間，標「字幕初稿」，不能聲稱逐字對齊或已聽審。更改字幕文字不會更改音軌；影片再剪輯後要重算並校對字幕。

## 執行與品質

- 依使用者要求建立環境及重現範例時，執行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\工具\setup.ps1 -Tts`；依本次使用者授權下載必要工具到本資料夾，不修改永久 PATH 或全域 Python。指定 `-Tts` 表示傳送公開範例旁白文字到線上 Edge TTS，非上傳影片；實際使用使用者提供文字前要清楚告知。網路或政策阻擋時如實報告，不要繞過學校限制。此腳本成功後包含課前設備檢查與新目錄成片。
- 基本示範使用 Pillow + FFmpeg 的 CPU `libx264` 軟體編碼，不要求 NVIDIA 獨立 GPU。電腦有 GPU 不等同已做低規實測；請記錄環境與實際用時。
- 預設示範靜音；`--tts` 使用 Edge TTS，會將旁白文字送至線上服務。提供的示例為可公開之無個資文字，其他文字按使用者授權處理；有聲與靜音輸出需明確標示。網路離線可改用使用者提供的合法聲音，或先生成無聲版本；影片、聲音、字幕不能自行上傳他人服務。
- 每個成果保留腳本、可修改素材、影片及字幕檔。檢查數學事實、字幕字形與斷句，抽取每場畫面查是否裁切、遮擋或錯字；用可用的影片工具確認檔案與聲軌，實際播放並逐句聽審旁白。未實際完成的步驟如實標註。
- 口播去停頓不能等同人聲分離；音量法與 VAD 都可能誤判。此工作區不把 Concat 0.2.9 內建自動字幕當必要流程（本機曾崩潰），也不自動使用 CapCut 內建字幕（使用者要求先停）。
- 上游原倉庫可在線上參照；其預設 4–8 分鐘／一鍵安裝與本文的輕量研習方案不同，不要照抄上游 README 的錯誤 clone 位址或自動執行其安裝腳本。
