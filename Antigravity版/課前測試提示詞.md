# 課前設備與操作測試

請先在 Antigravity 開啟本資料夾，再貼上：

```text
請讀取本工作區 AGENTS.md 和 README.md，為我的 Windows 電腦做課前設備與操作檢查。
我不一定有獨立顯示卡，請以 CPU 方式測試，不使用付費 API，也不要上傳我的影片或音訊。
我同意為本次研習在工作區建立專用的 Python、Pillow、edge-tts、mutagen 與含 FFmpeg 的 imageio-ffmpeg，請不要更改永久 PATH 或全域 Python。
我同意將本專案範例的旁白文字傳送到線上 Edge TTS，請執行 powershell -NoProfile -ExecutionPolicy Bypass -File .\工具\setup.ps1 -Tts，建立隔離環境並產生有聲示範。
請檢查 MP4 格式、時長、聲音與抽樣畫面，告訴我影片、字幕和可修改範例的路徑。校方政策、網路或權限阻擋時請回報，不要繞過。
請依實際結果標示已測通與未測通，不要只因檔案存在就聲稱字幕、音量、畫質已完全合格。
```

成功條件：能看到示範影片、清楚讀出畫面文字；有旁白版本要能聽到聲音並核對文字。老師需要剪既有影片時，再另外檢查 Concat 是否可開啟、MCP 是否已連線及能否輸出。以上是設備測試，不是學員考試。
