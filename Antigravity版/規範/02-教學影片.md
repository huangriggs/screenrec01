# 教學影片（研習簡化版）

目的：一支短片先教清楚一個概念。需求不明時合理選擇年段與題目，標明假設；不可把教材錯誤包裝成事實。使用者有指定課程長度與目標時優先遵循。

1. 寫出學習目標、一個易錯點、來源或教師給的材料，以及一個可驗算範例。
2. 安排 3–5 場：情境問題 → 解說步驟 → 示例 → 提問或回顧。場景的文字保持短，旁白與畫面互相補充。
3. 準備 `旁白稿`、分場內容與可編輯的 JSON／HTML 或工程資料夾；新增圖片或配音要記來源及使用者授權。
4. 先產出可播放初稿，再按場景檢查中文、字級、剪裁、數學正確性與對比；有旁白時完整聽審、比較字幕時間與語意斷句。
5. 匯出 MP4 和字幕檔，列出實際經過的檢查與仍需人工確認的項目。模型轉錄及腳本字幕都是初稿。

本版範例是 CPU 靜態圖卡，不等於原版動畫。完整原始參考：[上游原始規範](https://github.com/mathruffian-dot/claude-video-specs-lite/tree/main/specs)。設計思路參考 SOIL、motion-explainer 的教學結構與 review-loop 的逐場視覺檢查。
