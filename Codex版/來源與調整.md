# 來源與調整

- 上游：[mathruffian-dot/claude-video-specs-lite](https://github.com/mathruffian-dot/claude-video-specs-lite)，參考 Git commit `477567f9900535b14e1bf953bb3ec1d96a60c9cf`；原始授權見 [LICENSE](LICENSE)。
- 保留上游 `specs/`、`GOTCHAS.md` 作參考；部分舊機器絕對路徑已改為通用環境變數。本版不附上游 `install/`，其舊範例需要其他依賴，請以本版 `scripts/setup.ps1` 為入口。
- Codex 版改寫 README、AGENTS，將課堂流程調整為先檢查、先做短片，區分剪輯既有影片與從頭製作；提供環境檢查及 CPU 軟體編碼教學卡範例，可選 Edge TTS 中文旁白與分場 SRT。
- 保留各類型規範作延伸，但上游既定時長、機器路徑、全域安裝、視覺／語音條件不應凌駕使用者要求。上游 README 的 clone 指令指向原非 lite repo；本改版不沿用該指令。
- 自動準備環境的腳本下載 [uv](https://github.com/astral-sh/uv)、Python 和 Python 套件並建立專案內環境；FFmpeg 來自 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg)，線上中文旁白使用 [edge-tts](https://github.com/rany2/edge-tts)。
- 課堂設備最低條件、旁白逐字聽審、上游原版 HTML／HyperFrames 渲染及 Antigravity 實作須獨立測試。
