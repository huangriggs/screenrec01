# 課前設備與操作測試｜Codex

本表是**設備與操作測試**，不是學習成效測驗。預計使用 Windows；若學校有安裝限制，提前與資訊人員確認。

## 1. 檢查

在 Codex 開啟此資料夾後，先依 README 執行工作區環境準備；完成後執行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/課前檢查.py
```

| 檢查項目 | 用於 | 通過方式 |
|---|---|---|
| Codex 帳號與連線 | 收發指令 | 可建立對話並讓 Agent 回覆；本工具不檢查登入 |
| Python 3 | 本包 CPU 小範例 | 指令成功執行 |
| Pillow | 畫中文字幕卡 | 檢查顯示已安裝 |
| FFmpeg 與 libx264 | CPU 軟體編碼 | 檢查顯示可用 |
| 中文字型 | 範例卡片 | 自動找到，或在製作時以 `--font` 指定現有字型 |
| 儲存空間 | 範例與影片 | 留足素材、暫存與輸出空間；數值為顯示，不自動清理 |
| 既有素材 | 剪輯路線 | 可播放，並確認使用權及內容適合課堂 |
| Concat／MCP | 可選的可視化剪輯 | 自行開啟軟體；Agent 若要控制，必須另確認真正載入 MCP |

Codex 與首次下載工具、模型可能需要網路；無 GPU 不等於無需網路。`課前檢查.py` 只查本機基本環境，不測帳號、MCP、模型品質或所有依賴，也不判斷學校防火牆。

## 2. 一個可複製的示範

請在 Codex 對話貼上：

> 請讀 AGENTS.md 和 README.md，使用 scripts/setup.ps1 建立本專案的隔離環境並做課前檢查，再用 CPU 產生示範。我同意下載工具；若選用 `-Tts`，我同意將範例旁白文字傳送到 Edge TTS。請檢查影片和字幕，說明未完成的聽審項目，不上傳我的影音、不改全域設定。

預設示範是四張因數教學卡和靜音影像；有聲版本可選 `-Tts`，輸出獨立的分場字幕初稿。兩者均不是完整動畫效果。輸出使用新檔名，避免覆蓋。

## 3. 要使用老師自己的素材

> 請先幫我做一支約 30 至 60 秒的短影片。素材在我指定的資料夾，保留原始檔。先用現有的本機工具檢查環境，將影片整理成可繼續修改的專案並輸出 MP4。要加字幕時先產生可修改稿，標記不確定的詞，再與我確認。全程不要自行上傳素材。

需要 Concat MCP、語音模型或新增軟體時，Agent 需先確認相應功能可用、取得必要授權，且不應聲稱尚未測試的功能已完成。模型、轉錄工具及字幕處理**不是本包 CPU 靜音範例的必要依賴**。

## 4. 研習前的最後實測

請在課堂實際使用的電腦上，另行完成：開啟影片、剪一段、輸出、重新播放，若要用字幕，再測轉錄、修字與輸出。此處不指定全校硬體最低規格；速度、字型、權限和可用網路均以各台實際測試為準。
