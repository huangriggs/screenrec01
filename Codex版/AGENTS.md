# Codex 教學影片研習工作規則

以使用者指示為優先，以繁體中文協作。這份專案是由 claude-video-specs-lite 改編的 Windows 課堂工作包，目標是讓初學者能完成並檢查短教學影片。先閱讀 README、課前測試與提示詞、來源與調整；不要執行上游一鍵安裝腳本。

## 先確認任務

- 使用者已有素材要剪輯：走 Concat 手動剪輯，或在 MCP 連線確認後操作可編輯專案。字幕可用外部本機辨識後交給 Concat。VAD 是語音活動估計，不等於人聲分離；必須複聽剪點。
- 使用者要求全新動畫／影片：釐清教學對象、重點、片長、素材及旁白，根據可用資訊提出可修改的腳本與分鏡。使用者已授權就繼續製作，不需每一階段停下要求確認。
- 本包示例是 Pillow + FFmpeg CPU 卡片影片，可選 Edge TTS 旁白；與上游 HTML／Playwright 及 HyperFrames 動畫有別。不得將靜音影片描述成已完成旁白。

## 開始與交付

1. 老師要求建立環境並重現示範時，依 README 以 `scripts/setup.ps1` 建立工作區隔離環境；老師同意將範例文字送到 Edge TTS 時加 `-Tts`。按 Codex 的工具權限執行；不可聲稱已完成而未執行檢查與輸出。軟體編碼採 CPU；不得因偵測到 NVIDIA GPU 就自行啟用。
2. 使用本地化中文資料與經授權素材；不要自行上傳使用者影音。雲端 Agent 仍需服務連線，即使媒體推論在本機。Edge TTS 是線上服務，未確認網路時改用使用者提供的音檔或靜音初稿並標明。
3. 若使用者授權建立本專案必要依賴，可執行工作區隔離安裝；不批量安裝、不永久更改系統安全設定、不展示秘密。若缺依賴而無法完成，回報具體原因；不宣稱已測通。
4. 先完成短片可行性：影片大小、聲畫、繁體字、畫面清晰度與時間；逐段聽審旁白和字幕，特別核對同音字、數字和語意斷句。未聽審時標明限制。截圖抽查可佐證畫面，但不是完整視聽審查。
5. 保留輸入與可修改來源；輸出不覆蓋既有檔案，影片、SRT、素材及來源說明放在同一工作資料夾。

## 專案及兼容性邊界

- 程式／模型可本機執行，不代表 Codex 或其他雲端服務可離線；不將錄影等資料送到第三方，除非使用者授權目的地。
- 不預設 Whisper、Silero、Concat、MCP、HyperFrames 或字型已安裝，也不把單一電腦的測試視為所有無 GPU 電腦都適用。
- 上游範例可能含過時工具鏈、預設網路或較高依賴；本版不附上游 `install/`，請以本版 `scripts/setup.ps1` 為入口。上游 `specs/` 記載的時長是原版建議，使用者可選短片；如與本規則衝突，以使用者及本規則為準。
- 各工具下載可能涉及授權、可用性及費用變化；遵守當前環境政策和使用者指示。不要修改或覆蓋使用者原有的全域技能或 MCP 設定。
